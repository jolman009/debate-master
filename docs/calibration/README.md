# Phase 0 coach calibration protocol

The 72-slot manifest balances three difficulty levels, four topic families, two stances and three response-quality bands. It contains no fabricated learner responses or human scores. Rubric anchors and descriptive subskill tags live in `src/lib/debate/rubric.ts`; a coach must approve them before release.

Collect consented, de-identified transcripts in restricted storage. Replace transcript null with a restricted reference and consent false only after permission is established. Keep transcripts out of analytics and this public repository. Reserve this set from prompt tuning. Two coaches independently score all four dimensions blind to AI output and each other's scores: raterA/raterB use `{ "id": "rater-id", "scores": { "argumentStrength": 1, "evidenceUsage": 1, "rebuttalQuality": 1, "rhetoricalSkill": 1 } }`. These numbers illustrate shape, not labels to use. Adjudicate disagreements, retaining both original ratings and a separate rationale in the restricted review record. Populate adjudicated and ai with four dimension scores. Record evaluator model/prompt and timestamp alongside each AI run in the restricted record.

Run `node scripts/calibration.mjs path/to/completed-manifest.json`. Missing ratings, duplicate sample IDs, fewer than 60 complete cases, or any dimension below 80% within one point fails the proposed gate. Inspect all subgroup output and disagreement rationales before approval; small subgroup counts are not validation. Report rater disagreement, exclusions, sample counts and evaluator versions. Never describe the blank manifest as a coach-scored set or a passing calibration.
