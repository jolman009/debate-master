# Debate Master Brand Assets & Logo Guide

This document outlines the official Debate Master logo assets parsed from the source identity sheet.

## 🎨 Color Palette

| Token | Hex | Role |
| :--- | :--- | :--- |
| **Charcoal / Primary Dark** | `#1c1a19` | Podium outlines, desk, microphones, primary typography |
| **Charcoal Deep (Theme BG)** | `#1a1817` | App icon background, dark theme surfaces |
| **Antique Gold / Bronze** | `#b88d4c` | Fountain pen nib, inner podium pillars, accents |
| **Warm Gold Accent** | `#c59b4c` | Highlight gold in dark mode |
| **Editorial Cream (Foreground)** | `#f3ede3` | Light podiums and text on dark backgrounds |
| **Editorial Parchment (Surface)** | `#eee7dd` | Light badge background |
